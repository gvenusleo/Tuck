# Tuck

Tuck 是一款常驻 macOS 菜单栏的终端。展开后即可执行命令，收起后任务继续运行，再次展开时保留原有会话。

## 使用

启动 Tuck 后，菜单栏会显示应用图标。

| 操作 | 功能 |
| --- | --- |
| 按 Option + 空格（⌥ Space） | 展开或收起终端，在其他应用中也可使用 |
| 点击菜单栏图标 | 展开或收起终端 |
| 点击面板外部或切换应用 | 收起终端 |
| 右键点击菜单栏图标 | 显示“打开 Tuck”、“设置”和“退出 Tuck”菜单 |

收起面板会保留所有标签页的工作目录、环境变量和终端输出。每个标签页运行独立的登录 shell，新标签从用户主目录启动。只有一个标签时隐藏标签栏，终端占满面板；多个标签时显示与终端背景同色的紧凑标签栏，标题居中，不显示关闭图标。通过 `⌘T` 新建、`⌘W` 关闭当前标签，也可使用标签栏右键菜单。标签较多时可横向滚动，滚动条保持隐藏。

标题优先使用 shell 已有的目录上报信息，显示当前目录名，家目录显示 `~`，悬停显示完整路径。没有目录信息时使用终端标题，再按当前标签位置命名为“终端 N”，关闭标签后连续编号。Tuck 沿用 MyGo 的默认 shell 启动方式。本地 zsh 会启用 shell integration：通过临时 `.zshenv` 添加 OSC 133 提示符标记，避免调整宽度时右侧或多行提示符残留，并支持 Option+点击移动命令行光标。用户的 `ZDOTDIR` 和启动文件仍正常加载，不修改用户配置；其他 shell 不受影响。

输入 `exit` 或关闭标签只结束对应会话。关闭当前标签后优先选择右侧标签，没有右侧时选择左侧；关闭后台标签不会切走当前会话。最后一个标签关闭后面板收起，下次展开时创建新会话。

以下快捷键在终端面板内生效：

| 快捷键 | 功能 |
| --- | --- |
| `⌘T` | 新建标签页 |
| `⌘W` | 关闭当前标签页并结束会话 |
| `⌘⇧[` / `⌘⇧]` | 循环切换到上一个 / 下一个标签页 |
| `⌘1`～`⌘8` | 选择对应位置的标签页 |
| `⌘9` | 选择最后一个标签页 |
| `⌘,` | 打开设置 |

`⌥Space` 仍为全局展开/收起快捷键，不结束会话。设置窗口中的 `⌘W` 只关闭设置窗口。

选择“退出 Tuck”会结束全部会话并退出应用，重新启动后不会恢复上一次的标签页。

## 设置

右键点击菜单栏图标，选择“设置”。外观页可选择终端主题、等宽字体和字号，设置标签栏位于上方（默认）或下方，并调整面板宽高。更改自动保存；字号和宽高在离开数值输入区域或关闭设置时保存。主题、字体和字号保存后应用到全部会话；标签栏位置只改变布局，不重建终端；宽高在下次展开时生效。通用页可开启开机自启动。

终端面板默认尺寸为 720 × 420 DIP（逻辑像素），包含标签栏，终端填满其余空间。宽高接受正整数。展开时会根据所在屏幕的可用区域限制实际尺寸，为系统箭头和边框留出空间，保存的期望尺寸不变。

外观配置默认保存在 `~/.config/tuck/config.json`，也可通过 `XDG_CONFIG_HOME` 指定配置目录。设置窗口跟随系统明暗，终端使用独立选择的配色。开机启动由系统登录项管理。
