# Tuck

Tuck 是一款常驻 macOS 菜单栏的终端。展开后即可执行命令，收起后任务继续运行，再次展开时保留原有会话。

## 使用

启动 Tuck 后，菜单栏会显示应用图标。

| 操作 | 功能 |
| --- | --- |
| 按 Option + 空格（⌥ Space） | 展开或收起终端，在其他应用中也可使用 |
| 点击菜单栏图标 | 展开或收起终端 |
| 点击面板外部或切换应用 | 收起终端 |
| 右键点击菜单栏图标 | 显示“打开 Tuck”和“退出 Tuck”菜单 |

收起面板会保留工作目录、环境变量和终端输出。输入 `exit` 会结束当前会话并收起面板，菜单栏图标和快捷键仍然可用，下次展开时创建新会话。

选择“退出 Tuck”会结束会话并退出应用，重新启动后不会恢复上一次会话。

## 当前状态

当前仅在 Apple Silicon Mac 验证。
