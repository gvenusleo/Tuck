# Tuck

Tuck 是一款常驻 macOS 菜单栏的终端。展开后即可执行命令，收起后任务继续运行，再次展开时保留原有会话。

## 使用

启动 Tuck 后，菜单栏会显示应用图标。

| 操作 | 功能 |
| --- | --- |
| 按 Option + 空格（⌥ Space） | 展开或收起终端，在其他应用中也可使用 |
| 点击菜单栏图标 | 展开或收起终端 |
| 点击面板外部或切换应用 | 收起终端 |
| 右键点击菜单栏图标 | 显示“打开 Tuck”、“设置”和“退出 Tuck”菜单 |

收起面板会保留工作目录、环境变量和终端输出。输入 `exit` 会结束当前会话并收起面板，菜单栏图标和快捷键仍然可用，下次展开时创建新会话。

选择“退出 Tuck”会结束会话并退出应用，重新启动后不会恢复上一次会话。

## 设置

右键点击菜单栏图标，选择“设置”。外观页可选择终端主题、等宽字体和字号，并设置终端面板宽高。更改自动保存；字号和宽高在离开数值输入区域或关闭设置时保存。主题、字体和字号保存后应用到当前会话，宽高在下次展开时生效。通用页可开启开机自启动。

终端面板默认尺寸为 720 × 420 DIP（逻辑像素），宽高接受正整数。展开时会根据所在屏幕的可用区域限制实际尺寸，为系统箭头和边框留出空间，保存的期望尺寸不变。

外观配置默认保存在 `~/.config/tuck/config.json`，也可通过 `XDG_CONFIG_HOME` 指定配置目录。设置窗口跟随系统明暗，终端使用独立选择的配色。开机启动由系统登录项管理。
